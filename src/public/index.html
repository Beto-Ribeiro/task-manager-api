Endpoints REST Disponíveis

  • GET /health — Status de saúde e tempo ativo do servidor
  • GET /tasks — Lista todas as tarefas (suporta ?completed=, ?priority=, ?status=, ?search=)
  • GET /tasks/:id — Visualiza os detalhes de uma tarefa pelo ID
  • POST /tasks — Cria uma nova tarefa
  • PUT /tasks/:id — Atualiza título, descrição, prioridade ou status
  • PATCH /tasks/:id/toggle — Alterna rapidamente entre Concluída e Pendente
  • DELETE /tasks/:id — Remove uma tarefa permanentemente
